# SharpAcademy — платформа для изучения C# и .NET

Веб-платформа для обучения backend-разработке на C# / ASP.NET Core: теория → пример → практические задачи, плюс раздел подготовки к интервью.

## Как запустить

Просто открой **`index.html`** двойным кликом в браузере. Ничего устанавливать не нужно — всё работает офлайн (чистый HTML/CSS/JS).

## Структура

```
Course/
├─ index.html      # оболочка (навбар, подвал, точка входа)
├─ css/
│  └─ styles.css   # дизайн-система, анимации, тёмная тема
└─ js/
   ├─ data.js      # весь контент курса + вопросы для интервью
   └─ app.js       # движок: роутер, прогресс, подсветка кода, задачи
```

## Возможности

- **9 модулей, ~24 урока**: ADO.NET, Dapper, асинхронность, Web API, DI/Middleware/Logging/Config, EF Core, паттерны API, безопасность (JWT, Identity, роли), производительность (фоновые задачи, кеш).
- **Структура урока**: теория → живой пример с подсветкой C# → 3–10 задач по одной (подсказка, решение, пропуск).
- **Раздел «Интервью»**: флеш-карты с вопросами и ответами по категориям.
- **Прогресс**: XP за задачи, уровни, стрик по дням, общий прогресс — всё сохраняется в браузере (localStorage).
- **Сертификат**: открывается после прохождения всех уроков, можно впечатать имя и распечатать / сохранить в PDF.

## Как добавить контент

Весь контент — в `js/data.js`. Чтобы добавить урок, допиши объект в массив `lessons` нужного модуля:

```js
{
  id: "unique-id",
  title: "Название урока",
  duration: "20 мин",
  theory: `<h3>Заголовок</h3><p>текст...</p>`,
  example: { lang: "csharp", note: "описание", code: `код...` },
  tasks: [
    { t: "Название", d: "easy|medium|hard", desc: "...", input: "...", output: "...", hint: "...", solution: `код` }
  ]
}
```

Вопросы для интервью — в объекте `INTERVIEW` там же.
